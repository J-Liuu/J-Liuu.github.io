## p5.js Flower - Procedural Graphics

Duration: 2 Weeks
Link: https://editor.p5js.org/jackyliu432/sketches/OWZIvngLd

Overview:
This project was inspired by Janos Karsai and explores procedural flower generation using mathematical principles. The flower is generated in 3D using trigonometric functions and parametric equations.

My Contribution:
I developed this interactive flower visualization applying various mathematical concepts including:

- Polar Coordinates: Used to generate the petal formations.
- Power Functions: Modify petal sharpness and curvature.
- Exponential Decay: Shapes the stem and gradual cone-like structure.
- Bump Mapping: Adds texture variations to the petal edges.

The flower dynamically updates using p5.js, demonstrating mathematical visualization techniques.

Demonstration:
The interactive visualization above shows the flower in action. You can click on it to toggle auto-rotation or manually control the camera by clicking and dragging.

## Cooking Havoc RPG

Duration: 5 weeks
Links:
- https://j-liuu.itch.io/cooking-havoc
- https://docs.google.com/spreadsheets/d/1P7m7JISunexrorbSa00R3xcTQbOfaRtxyE6ZIFYEWjI/edit?usp=sharing

Overview:
A static cooking/exploration RPG that combines cooking mechanics with data-driven gameplay. Features a backend system for tracking player behavior and game analytics.

My Contribution:
Role: Systems Programmer & Datahook architecture

Two person project. Built a Twine-based data-logging system that tracks player location visit counts and sends them in real-time to Google Sheets. Utilized Harlowe scripting language and integrated calls to Google Apps Script web app for Cooking Havoc's data transmission. The system was inspired by Blizzard's Datahooks architecture used in their MMORPG systems, allowing for detailed player behavior analysis and game balancing insights.
